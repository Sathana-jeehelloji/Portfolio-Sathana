📌 Pinterest Replica – UI/UX Design

Tool: Figma
Role: Solo Designer
Goal: Recreate Pinterest’s core user experience with a fresh and modern design.

🔍 What I Did

  • Analyzed Pinterest's interface and user flow
  • Redesigned the home feed, pin detail, search, and profile screens
  • Built a clean, responsive layout using Auto Layout, Components, and Variants in Figma
  • Prototyped smooth navigation and micro-interactions

🎨 Design Highlights

✨ Key Elements:
  • Soft, neutral color palette
  • Grid-based layout for consistency
  • Intuitive navigation and clear call-to-actions

💡 Outcome

Enhanced my skills in UI structuring, reusable design systems, and user-centered redesign.
The prototype is ready for user testing and further refinement based on feedback.
