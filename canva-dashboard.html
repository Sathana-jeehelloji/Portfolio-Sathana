Netflix Streaming Content Velocity Dashboard

Transforming unstructured streaming platform catalog metrics into an elegant, viewer-friendly visual dashboard synthesizing genres, movie vs TV production ratios, and multi-year release velocities.

Creative Tool Canva UI Design
Role Dashboard Designer
Dataset Netflix Catalog Records
Core Focus Data Storytelling & UX

🎬 Overview & Goals

  • Analyzed streaming content distributions across international territories, age maturity ratings, and release eras.
  • Engineered a high-contrast layout system incorporating custom typography, recognizable streaming iconography, and strict spatial grids.
  • Synthesized content ratios to evaluate the strategic shift from legacy licensed movies towards serialized TV Originals.

📊 Key Visual Artifacts

  • Genre Distribution Breakdown: Color-coded categorization detailing drama, comedy, and thriller share.
  • Volume Differential: Clear comparative bar metrics evaluating runtime length and format splits.
  • Historical Timeline: Yearly release volume curves documenting rapid platform growth over the past decade.

💡 Learning Outcomes

Reinforced core visual design fundamentals: managing visual hierarchy, whitespace distribution, and transforming analytical figures into engaging communication that anyone can grasp in seconds.
