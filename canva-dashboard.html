🎬 Netflix Data Dashboard – UI Design

Tool: Canva
Role: Dashboard Designer
Dataset: Netflix Content Data (Genres, Ratings, Release Year, Type)
Goal: Visually represent key streaming insights through a clean, viewer-friendly dashboard.

🔍 What I Did

  • Analyzed Netflix data to identify patterns in genre distribution, content type, release trends, and ratings
  • Designed an aesthetic dashboard layout in Canva using charts, icons, and visual hierarchy
  • Focused on clarity, spacing, and data storytelling with minimal visuals

📊 Dashboard Highlights

✨ Key Features:
  • Genre pie chart with color-coded categories
  • Bar chart comparing movies vs. TV shows
  • Timeline graph of yearly content releases
  • Minimalist design using Canva’s grid and icon tools

💡 Outcome

Practiced data storytelling through visual UI/UX design.
Learned how to simplify data-heavy content using Canva’s design system.
