Movie Reviews & Interactive Catalog Web Application

A fully responsive, client-side web application developed with HTML5, CSS3, and Vanilla JavaScript featuring dynamic movie catalog cards, interactive 3D flips, star ratings, and real-time review forms.

Tech Stack HTML5, CSS3, JavaScript
Role Front-End Developer
Architecture Vanilla Web Application
Live Deployment Included Locally

🎥 Architecture & Features

  • Engineered an engaging media showcase layout displaying posters, cinema genres, release dates, and trailer links.
  • Implemented 3D CSS perspective transforms and hover flips revealing detailed synopsis and rating metadata.
  • Engineered interactive JavaScript form handlers for dynamic user reviews with client-side validation.
  • Guaranteed cross-browser responsiveness and mobile usability using fluid CSS Flexbox and Grid layouts.

💻 Interactive Capabilities

  • Dynamic Catalog: Curated movie cards featuring Inception, Interstellar, The Dark Knight, and Avengers: Endgame.
  • Interactive 3D Flips: Smooth CSS perspective rotations revealing synopsis and trailer triggers.
  • Review Submission Engine: Form state management dynamically updating client feedback.

💡 Learning Outcomes

Reinforced low-level DOM manipulation, event handling, responsive CSS architecture, and creating engaging web interfaces from scratch without framework overhead.
