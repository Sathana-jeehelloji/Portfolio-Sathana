Applied Machine Learning & Python Software Systems

A technical breakdown of two applied Python engineering projects: (1) A deep Convolutional Neural Network (CNN) for agricultural plant leaf pathology diagnosis, and (2) A real-time meteorological API telemetry application.

Project 01 // Deep Learning

Plant Disease Classification via Deep CNN

TensorFlow / Keras OpenCV Computer Vision 95%+ Accuracy

🌿 Architecture & Methodology

  • Acquired and augmented comprehensive agricultural leaf datasets to represent varying lighting angles and disease progressions.
  • Engineered image preprocessing pipelines using OpenCV including resizing, color space normalization, and morphological enhancements.
  • Trained convolutional neural network architectures using TensorFlow and Keras with dropout regularization to avoid overfitting.
  • Evaluated model precision using confusion matrices, F1-scores, and multiclass accuracy metrics.

💡 Real-World Impact

Enables non-expert agricultural operators to rapidly identify fungal and bacterial leaf pathogens before widespread crop damage occurs, demonstrating how edge AI can deliver measurable agricultural value.
